# Metacognitive Strategies

A lightweight single-page web application that presents metacognitive strategy prompts for classroom use.

## Application Overview

The app organizes prompts into five strategy areas:

- **Orient**: understand the problem and set goals
- **Plan**: decide steps and strategies
- **Monitor**: check progress while solving
- **Evaluate**: assess solution quality
- **Reflect**: review learning and transfer skills

## Features

- Clean tabbed interface for strategy-focused prompts
- Keyboard navigation support for accessibility
- **Show All** toggle to display all strategy prompt lists
- Print button for printable classroom handouts
- Responsive layout for desktop and mobile

## How to Use

1. Open `index.html` in a web browser.
2. Select a strategy from the left panel to view its prompts.
3. Use **Show All** to view all prompts together.
4. Use **Print** to print the current prompt view.
